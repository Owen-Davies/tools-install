# Host-specific extras for the x13 ThinkPad, run after profiles/desktop.txt.
#
# Built for the Server+dwm rebuild of this laptop (no ubuntu-desktop/GNOME):
# desktop.txt already covers keyd/yubikey/pass/code/snap/flatpak/dotnet/deno
# without depending on GNOME being present -- everything here is either dwm's
# own session stack (nothing else provides one without GNOME's gdm3), or apps
# from the old GNOME install that don't have a home in any generic profile.
#
# Order matters: X11 + window manager + display manager before apps that
# assume a GUI exists.

# --- window manager / session (required -- no session without these) ---------

# (modkey, gaps, colours, keybinds), run `dwm-apply-config` from dotfiles/bin
# once dotfiles' own install.sh has run (needs ~/bin on PATH). Not wired in
# here: install-profile.sh's manifest format only resolves script names
# within this repo, and dotfiles may not have run yet at this point.

!lightdm.sh
